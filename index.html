GitHub 同期

Personal Access Token (PAT) を設定すると、記録が自動で GitHub にコミットされます。 トークンはこの端末のブラウザにのみ保存されます。

PATの作り方: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens で、このリポジトリへの Contents: Read and write 権限を付与したトークンを作成。

バックアップ

記録データをJSONとしてダウンロード・取り込み。
